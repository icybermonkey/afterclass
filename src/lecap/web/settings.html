lecap settings

Global for all lessons, saved in …. Changes save immediately. API keys go to the macOS Keychain, never into a file.

Lessons

Defaults for new runs of lecap <video> <folder>. A flag on the command line always wins.

AI

“auto” uses a local model when one is running (offline), otherwise Claude. Online models only ever get text (transcript and slide text), never the video.

Local AI (offline)

Runs on this Mac with LM Studio or Ollama. Needed once: an app, a model, and its server running.

Claude API key

Only for the “claude” provider (pay per use, ≈ $0.35 per lecture). The “claude-code” provider uses your Claude subscription and needs no key.
